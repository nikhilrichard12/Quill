# Import meeting notes
Bring your existing meeting transcripts and summaries into Littlebird from another app so everything lives in one place.

## How to import

If you have meeting notes, transcripts, or summaries in another app, you can import them into Littlebird so everything is searchable and referenceable from Chat.

- Go to Settings → Import

- Select the app you want to import from

- Follow the on-screen instructions to connect and transfer your notes

Once imported, your previous meeting notes are treated like any other Meeting Note in Littlebird. They are searchable, appear in Meeting Notes, and can be referenced when you ask questions in Chat.

Note

The available import sources depend on which apps Littlebird supports at the time. Check Settings → Import for the current list.
