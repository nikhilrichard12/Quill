# First Chat
Ask Littlebird about recent work, sharpen the answer with a follow-up, and keep each conversation focused.

Start with something you recently read, discussed, or worked on. You do not need to remember where it came from.

Prompt

What were the main decisions from my latest meeting with the marketing team? Include the meeting note and any related links.

## Make the answer more useful

If the first answer is close, stay in the same Chat and tell Littlebird what to change:

- ask for a shorter summary or more detail;

- name a missing person, project, or source;

- request a checklist, table, email, or another useful format;

- ask Littlebird to turn the answer into the next piece of work.

For example:

Prompt

Turn those decisions into a short update for the team. Put the action items at the end and group them by person.

Littlebird remembers the current conversation, so you do not need to repeat the earlier answer.

## Keep Chats focused

Use one Chat for one outcome. Continue in the same thread while you refine a plan, draft, or decision. Start a new Chat when the next request is unrelated.

Star a conversation when you expect to reuse it. Past conversations remain available under Recents.
