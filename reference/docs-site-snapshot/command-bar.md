# Command Bar
Use the command bar to jump between chats, find meeting notes, and trigger contextual actions without leaving your keyboard.

## What the Command Bar does

The Command Bar is a quick way to navigate the app and search across your chats and meeting notes. Press Cmd+K (Ctrl+K on Windows) to open it from anywhere.

## Navigation

Start typing to search across:

- Chat conversations

- Meeting notes

- Settings sections

- Other parts of the app

Select a result to jump straight to it.

## Contextual actions

The Command Bar also shows actions based on where you are. For example, if you open it while viewing a chat, you’ll see options like:

- Download chat as markdown

- Copy chat link

More contextual actions will be added over time.

Tip

If you see stale data in Meeting Notes or Glance – for example, a meeting that’s no longer there or a routine that already ran still showing as pending – try Reset Local Database from the Command Bar or Settings. This acts as a hard refresh, clearing cached data and refreshing Littlebird from the cloud.
