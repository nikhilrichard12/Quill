# Better prompts
Get a more useful answer by stating the outcome, relevant context, constraints, and shape you need.

You do not need to learn a prompting framework. Start with what you want, then add only the details that would change the answer.

## Ask for the outcome

Lead with the job you want Littlebird to complete. “Prepare me for the call” is more useful than a broad request to “look into the client.”

## Point to relevant context

Mention the person, project, date, document, or conversation that matters. Littlebird can use your recent work and connected tools, but a clear reference helps it choose the right context.

## Add useful constraints

Say what the answer must include, what it should leave out, or how current the information needs to be. Add a deadline, audience, or tone when it affects the result.

## Choose a useful shape

Ask for the format you will actually use: a short briefing, checklist, table, email draft, project plan, or another concrete deliverable.

Here is all four ideas in one request:

Prompt

Prepare me for my call with [name] tomorrow. Review our recent conversations, the latest project plan, and any open action items. Give me a briefing I can read in five minutes, followed by three questions I should ask.

## Refine the answer

If the first response is close, stay in the same Chat and say what to change. You can ask Littlebird to make it shorter, add evidence, use a different tone, or turn the answer into another format.

Start a new Chat when the next request is unrelated. This keeps the conversation focused and makes useful threads easier to find later.
