# Projects
Keep related conversations and meetings together with per-project instructions, file uploads, and scoped context.

## What Projects do

Projects group related chats and meetings together, like folders for a body of work. Planning a product launch? Create a project, move your brainstorming chats, strategy docs, and meeting notes into it, and everything stays organized in one place.

Create a project from the sidebar. You can star a project to keep it pinned at the top.

## Per-project Instructions

Each project has its own Instructions field where you set standing guidance for how Littlebird should respond inside that project. For example:

- “This project is for Q4 planning. Always reference the attached roadmap first.”

- “I’m researching competitor pricing. Ground answers in the attached files.”

- “Respond in Spanish for this project.”

Instructions save you from repeating context every time you start a new chat within the project.

## Files

Upload any relevant files to a project. Those files are accessible by all chats within the project, so you don’t need to re-attach them each time.

## Context scope

By default, a project cannot access conversations you’ve had with Littlebird outside the project. This keeps each project’s context focused. If you want a project to also reference your other conversations when relevant, you can toggle this behavior in the project’s settings.

## Moving chats and meetings into a project

You can move existing chats and meetings into a project from the See all chats view. Select one or more chats, then choose Add to project from the bulk actions bar.
