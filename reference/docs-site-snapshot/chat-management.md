# Manage chats
Search, filter, and organize your chats in bulk. Archive chats you are done with, delete the ones you do not need, and add chats to projects.

## See all chats

Hover over Recents in the sidebar and click the arrow icon that appears. This opens the full Chats view, showing every conversation in one list with a search bar and filter button at the top.

From here you can:

- Search by keyword to find any chat

- Filter to narrow down by project, date, or other criteria

- Multi-select chats using the checkboxes on the left

## Bulk actions

When you select one or more chats, a floating action bar appears at the bottom with:

- Add to project - move the selected chats into a project

- Archive - hide the selected chats from your sidebar

- Delete - permanently remove the selected chats

## Archiving vs deleting

Archiving a chat hides it from the sidebar. It moves to Settings → Archived Chats, and you can restore it anytime. Archived chats still appear in search results (Cmd+K or Ctrl+K) and can still be referenced when you ask Littlebird about past conversations.

Deleting a chat is permanent. It disappears from your chat list and from search, and Littlebird can no longer pull it up.

Note

If you are not sure whether you’ll need a chat again, archive it. You can always delete it later from Settings → Archived Chats.
