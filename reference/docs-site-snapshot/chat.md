# Chat
Start a conversation, add the context Littlebird needs, and keep useful Chats easy to find and continue.

Chat is where you ask Littlebird to find, explain, plan, or create something.

## Start a Chat

Select New Chat, write what you need in the prompt box, then send it.

Each new Chat starts with a clean slate. Keep one piece of work in each Chat, and continue in the same thread when you want Littlebird to refine an answer or build on an earlier step.

Past conversations appear under Recents. Star the ones you expect to return to.

## Add what Littlebird needs

The controls beside the prompt box let you:

- attach a document or image for that Chat;

- use available integrations to bring in connected information;

- turn on Max mode for work that benefits from more thorough, multi-step reasoning;

- dictate your request with the microphone.

The available tools depend on your plan, connected integrations, and approved permissions.

## Keep and share useful work

Select the Star icon to add a Chat to your favorites.

Select the Share icon at the top right of a Chat (next to Star) to open Share chat. Choose Private, Team members, or Public access. Only messages up until now are included; open Share again to include later messages. See Sharing a chat for the full steps.

Littlebird remembers the conversation within the current thread. You can review saved Chat Notes under Settings → Chat.

## Give feedback

Use the thumbs-up or thumbs-down control when a response helps or misses the mark. If you downvote a response, add a short explanation of what you expected so the feedback is more useful.
