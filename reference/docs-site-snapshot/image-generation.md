# Generating images in Chat
Ask Littlebird to create, draw, or generate an image from a text description without leaving your conversation.

## How it works

You can generate images from text descriptions directly in Chat. Just ask Littlebird to create, draw, or generate an image.

Example prompts:

Prompt

Generate an image of a minimalist workspace with a laptop, coffee, and a plant on a clean white desk.

Prompt

Draw a simple logo for my project - a stylized bird in blue and white.

Prompt

Create a hero banner image for a landing page about AI productivity. Wide format, modern aesthetic.

## Tips for better results

- Be specific about style - mention if you want photorealistic, illustrative, cartoon, minimalist, etc.

- Describe composition - include framing, lighting, colors, and mood

- Specify format - mention if you need landscape, portrait, or square

- Iterate - if the first result isn’t quite right, ask for adjustments like “make the sky darker” or “add a dog in the corner”

The generated image appears directly in the chat. You can download it to your device or reference it in further conversation – just ask Littlebird to modify or build on the image it created.
